# HomeBurn

Burn calories at home — bodyweight only. Your phone counts every rep.

**Slogan:** *Phone up. Body moves. Calories burn.*

## Features
- Jump rope, push-ups, squats, sit-ups, pull-ups, mountain climbers
- Camera-based rep counting (MediaPipe Pose)
- Sound fusion for jump rope
- Auto exercise detection & switch
- Local calorie & session log
